# Contributing to RAPID Live (abb-rws-vscode)

Thank you for your interest. The project is in early development, so the most useful contributions right now are:

- Issues describing your controller, RobotWare version and use case
- Reports of RWS behaviour that differs between RobotWare versions

## Pull requests

- Open an issue first for anything larger than a small fix.
- Contributions are accepted under the Apache-2.0 licence (Section 5 of the licence).
- Sign off your commits (`git commit -s`) to certify the [Developer Certificate of Origin](https://developercertificate.org).
- Do not include code copied from ABB SDKs, ABB documentation or projects with incompatible licences.

## Safety

This software talks to industrial robot controllers. Test against a virtual controller in RobotStudio before connecting to real hardware.
